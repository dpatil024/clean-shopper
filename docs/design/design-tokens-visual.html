Clean Shopper — Design Tokens

foundation layer · inspired by seed.com
warmed and slowed down on purpose

Checking whether a product is safe can feel anxious if the interface amplifies it. This system is tuned to stay calm under the specific moment it exists for — a warm, buttery base instead of clinical white, a terracotta "avoid" instead of alarm red, loose type instead of tight tracking, and motion that settles rather than snaps.

Color

One soft ink, one warm base, one honey accent used sparingly — and a verdict system that reads as guidance, not a warning light.
